## アウトプットの課題と施策

課題
・AIに頼りすぎると自分で考えるフェーズが減り身につかない
・日記は仕事していると代わり映えせず書くことがなくなる
・知っているお題だと同じ表現ばかり使いがちになる
・ニュアンスの違いを意識したいが、毎回AIに問い合わせるのが面倒
・コピペを禁止する（自分で入力させる）
・モチベ維持が難しい（継続性とストレスの塩梅）

施策
・AI添削: 文法的・ネイティブ的など複数グラデーションのフィードバック
・お題の自動提案: 知らないテーマ・使ったことない表現を意図的に出す
・傾向分析: 過去作成文章から使いがちな表現・苦手パターンを分析
・コピペ禁止: テキストエリアへの貼り付けを制御
・報酬設計: 継続ポイント・採点ポイントなどのゲーミフィケーション
・アシスト量のコントロール: どこまでヒントを出すかユーザーが選べる


## マネタイズ
フリーミアム構成
・無料プラン: 登録できる単語数・例文数に上限
・有料プラン: 上限解除、フォーカス単語機能、AI生成回数増加 など


## 継続課題
・アシスト量のコントロール設計
・アウトプット形式の詳細（穴埋め・チャンク組み立てなど）
・失敗リストの入り方（自動 / 手動）
・お題レコメンドロジック: フォーカス単語・作文傾向・資格タグを材料にパーソナライズ、実装しながら段階的に強化

## Personalized example sentences

Treat personalized example sentences as precomputed learning content, not as a user-triggered generation feature. AI can be the implementation detail behind the scenes, but the product concept is personalization.

- The learner should primarily browse ready-made examples during study.
- The UI does not need a visible "Generate" button for the first version.
- Each vocabulary entry can hold additional example sentences separately from the curated primary example.
- Personalization should happen asynchronously in the background.
- A user profile update can trigger regeneration using the latest personal context, such as interests, work context, goals, weak vocabulary, or saved focus words.
- The personalized result should be stored and served as normal learning content, so the display layer does not depend on live generation.
