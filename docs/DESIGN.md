# Design Direction

## Mood
- Warm
- Playful
- Motivating

## Base Direction
**Base:** B (Gentle gamification)
**Also borrow from:** Duolingo (Streak UI)
**Explicitly not using:** Duolingo (Mascots, Loud colors)

## Reference Analysis

### Duolingo
**This (borrow):**
- Streak UI (visualizing continuous learning days)

**Not that (reject):**
- Mascot characters (distracts from writing English)
- Loud, highly saturated colors (tiring for daily use)

## Comparison Matrix

| Reference | Mood | Information density | Color tone | Primary borrow | Reject |
|-----------|------|---------------------|------------|----------------|--------|
| Duolingo | Playful | Low | Loud | Streak UI | Mascot, Loud colors |
| **This App** | **Warm, Motivating** | **Medium** | **Calm, Warm** | **Streak UI** | **Mascot, Loud colors** |

## Anti-references (Hard Rejects)
- Purple gradient on white (generic AI look)
- Excessive badges / notification spam
- Dashboard cramming unrelated metrics
